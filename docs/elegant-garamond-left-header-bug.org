* What Was Tried

** 1. Token-register fallback in header definition

Attempted:
- check whether =\the\leftheader= is empty
- fall back to =\@title=
- optionally wrap in =\href{...}= if =\the\leftheaderurl= is non-empty

Initial implementation used =\ifdefempty= and was likely wrong for token-register contents.

** 2. Switched emptiness check to =\ifstrempty=

Updated both templates to use =\ifstrempty{\\the\\leftheader}{\\@title}{\\the\\leftheader}=.

This fixed one probable macro misuse, but the left header still did not render.

** 3. Delayed left-header resolution to =\AtBeginDocument=

Moved the left-header assignment so it happens after Org-generated LaTeX like =\title{...}= should already exist.

Current pattern in both templates:
- define =\jayapplyleftheader=
- resolve =\@title= or =\the\leftheader=
- call =\lhead{...}= inside =\AtBeginDocument=

The templates still load cleanly in batch Emacs with =ox-latex= required, but runtime export output still lacks the left header.

* Current Risk

* Resolution (2026-04-20)

*Root cause*: =\ifstrempty= from etoolbox detokenizes its first argument *without expanding it first*. So =\ifstrempty{\the\leftheader}{...}{...}= tested whether the literal 16-character string =\the\leftheader= was empty — which it never is — so the fallback branch could never fire.

Verified with a minimal =pdflatex= test: =\ifstrempty{\the\myheader}{EMPTY}{NONEMPTY}= prints =NONEMPTY= even when =\myheader= is an empty token register. Wrapping the token register in =\edef\resolved{\the\myheader}= and then calling =\ifstrempty{\resolved}= has the same problem — the detokenized string =\resolved= is still non-empty. Only =\ifx\resolved\@empty= correctly sees the empty register.

*Fix*: expand the token register into a macro with =\edef=, then compare against =\@empty= with =\ifx=. Applied to both [[file+emacs:/Users/jay/emacs/emacs-settings/latex-templates/elegant-garamond.el][📄 elegant-garamond.el]] and [[file+emacs:/Users/jay/emacs/emacs-settings/latex-templates/elegant-garamond-tabularray.el][📄 elegant-garamond-tabularray.el]]:

#+begin_src latex
\makeatletter
\newcommand{\jayapplyleftheader}{%
  \edef\jayresolvedleftheader{\the\leftheader}%
  \ifx\jayresolvedleftheader\@empty
    \edef\jayresolvedleftheader{\@title}%
  \fi
  \edef\jayresolvedleftheaderurl{\the\leftheaderurl}%
  \ifx\jayresolvedleftheaderurl\@empty
    \lhead{\scshape\jayresolvedleftheader}%
  \else
    \lhead{\scshape\href{\the\leftheaderurl}{\jayresolvedleftheader}}%
  \fi}
\makeatother
#+end_src

Confirmed working against the reproduction file — left header on page 2+ now falls back to =#+TITLE:= when =\leftheader{...}= is omitted.
