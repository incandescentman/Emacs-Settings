* Overview

The ~beautiful-racket~ template is a custom LaTeX class for org-mode export, designed for professional document production with Tufte-inspired typography.

Template location: [[file+emacs:/Users/jay/emacs/emacs-settings/latex-templates/beautiful-racket.el][Beautiful Racket template]].

* Usage

To use this template, add to your org file's export settings:

#+begin_example
#+LaTeX_CLASS: beautiful-racket
#+end_example

* Tables

** Preferred Format

Use this format for tables that may have wide content:

#+begin_example
#+ATTR_LATEX: :booktabs t :environment tabularx :width \textwidth :align lXXX
| \textbf{Header1} | \textbf{Header2} | \textbf{Header3} | \textbf{Header4} |
|------------------+------------------+------------------+------------------|
| Data             | Data             | Data             | Data             |
#+end_example

** Table Attributes

| Attribute               | Purpose                                              |
|-------------------------+------------------------------------------------------|
| ~:booktabs t~           | Professional horizontal rules (toprule/midrule/bottomrule) |
| ~:environment tabularx~ | Auto-wrapping columns that fit page width            |
| ~:width \textwidth~     | Table spans full text width                          |
| ~:align lXXX~           | Column alignment specification                       |

** Column Alignment

- ~l~, ~c~, ~r~ - Fixed-width columns (left, center, right aligned)
- ~X~ - Wrapping column that expands to fill available width

Use fixed columns for short content (Year, numbers, short labels).
Use ~X~ columns for longer text that should wrap.

Examples:
- ~lXXX~ - First column fixed, next three wrap
- ~lXlX~ - Alternating fixed and wrapping
- ~lXX~ - Three columns: fixed, wrap, wrap

** Header Formatting

- Use ~\textbf{Header Text}~ for bold headers
- Add separator line ~|---+---+---|~ after header row
- The separator triggers booktabs ~\midrule~

** Template Features for Tables

The template includes:
- ~tabularx~ package for auto-wrapping tables
- Ragged right alignment in X columns (prevents awkward justification)
- ~booktabs~ package for professional table rules

* URLs and Links

** Long URL Handling

The template includes the ~xurl~ package which allows URLs to break at more points, preventing overflow in bibliographies and references.

Configuration in template:
#+begin_example
\usepackage{xurl}
\usepackage[breaklinks=true,linktocpage,xetex]{hyperref}
#+end_example

** Link Colors

All links use ~elegantblue~ color (#4380b9):
- Citations
- File links
- Internal links
- URLs

* Typography

** Fonts (XeTeX)

When compiled with XeTeX:
- Roman: Garamond Premier Pro
- The ~\sffamily~ slot uses TeX Gyre Pagella, a serif face, for subsection headings.
- The ~\ttfamily~ slot uses TeX Gyre Heros, a proportional sans-serif face, for levels one and three and for listings. The slot name does not make it monospaced.
- Level four uses Helvetica Neue LT Pro Bold Condensed; level five uses bold Garamond Premier Pro.

** Tufte-Style Features

- ~\newthought{text}~ - Start a new section with small caps
- ~\smallcaps{text}~ - Letterspaced small caps
- ~\allcaps{text}~ - Letterspaced all caps
- 12pt body with the standard article size ladder: ~\small~ is 10.95pt, ~\footnotesize~ is 10pt, ~\large~ is 14.4pt, and ~\Large~ is 17.28pt. The former 10pt override was removed on 2026-10-11 after Jay selected 1B.

** Spacing

- No paragraph indentation
- 8pt paragraph skip, with 1pt stretch or shrink
- 1.18 line stretch applied to the 14.5pt normal baseline
- Small raised bullets and existing list indents; ~noitemsep~ with ~topsep=-4pt~ keeps the lists compact at the smaller paragraph gap.
- Outer bullet and numbered lists stay with their introduction; nested lists retain the original break penalty.
- Class-local ~\lefthyphenmin=3~ avoids two-letter fragments before automatic hyphen breaks, alongside the shared prose defaults.

* Page Layout

- Paper: 8.5" x 11" (US Letter)
- Horizontal margins: 1.5"
- Top margin: 0.5" (includes header)
- Bottom margin: 1"

* Headers and Footers

- Left header: Configurable via ~\leftheader~ token, with an optional ~\leftheaderurl~; empty unless the document supplies text. There is no title fallback.
- Right header: Current subsection name
- Both headers use 9pt small caps with a 12pt baseline. Bounded widths of 30% and 67% permit wrapping; 28pt head height accommodates two lines.
- Center footer: Page number
- No header rule
- TOC page: No page number
- Long contents entries can wrap between words using ~\cftsetrmarg{2.55em plus 1fil}~.

* Headings

** Section Hierarchy

- Section: 40pt TeX Gyre Heros, small caps, right-aligned.
- Subsection: 24pt TeX Gyre Pagella serif.
- Subsubsection: 18pt TeX Gyre Heros, small caps.
- Paragraph: a true 10pt Helvetica Neue LT Pro Bold Condensed uppercase label, 9% tracking, red ~#C0261F~, on its own line.
- Subparagraph: 12pt bold Garamond Premier Pro, on its own line.

Levels four and five are Jay's selected 2B treatment. Levels one through three retain their existing design. Space reservations for levels three through five keep headings with their opening text without separating consecutive headings.

** Custom Environments

- ~subtitle~ - 18pt italic text below section headings (no hyphenation, ragged right)
- ~subsubtitle~ - Normal italic text below subsection headings
- ~tagline~ - 17.28pt italic intro text with adjusted margins
- ~fauxtitle~ - 17.28pt bold display text
- ~fauxcenter~ - 17.28pt centered display text
- Figure and table captions use 14.4pt bold text.

* Block Quotes

Block quotes are styled with:
- Powder blue background (#f5f7ff)
- Stormy blue-grey border (#708090)
- Moon rock grey text (#5D5D5D)
- Rounded corners
- 80% text width, centered
- Breakable across pages

- The ~\ttfamily~ font at ~\small~ size; this template assigns proportional TeX Gyre Heros to that slot.
- Single frame border
- Line breaking enabled

* Endnotes / Works Cited

The template loads ~enotez~ but leaves endnotes disabled by default. Ordinary Org footnotes remain page footnotes unless endnotes are explicitly enabled.

** How It Works

- Use Org footnote syntax such as ~[fn:1]~ for inline references and define each footnote in the source.
- Add ~#+LATEX_HEADER: \EnableEndnotes~ to redirect exported footnotes to endnotes.
- Place ~#+LATEX: \printendnotes~ where the endnotes should appear. A Works Cited heading by itself does not print them.

** Formatting

The template does not configure a custom endnote list, suppress the package's endnote heading, or suppress the running header on a Works Cited page. Those were incorrectly described as automatic features in the earlier documentation; corrected 2026-10-11.

** Minimal endnote export settings

Add ~#+LATEX_HEADER: \EnableEndnotes~ to the document settings. After the body, add ~#+LATEX: \printendnotes~. Keep the usual Org footnote references and definitions; no separate hand-written Works Cited heading is required for the package's default heading.

** Reference syntax

The original reference example below illustrates Org syntax only. Its Works Cited heading does not enable or print endnotes; use the export settings above for that behavior.

#+begin_src org
Some text with a reference.[fn:1] More text.[fn:2]

** Works Cited

[fn:1] Author, "Title," Publication, date, [[url][Link]]

[fn:2] Another source...
#+end_src
